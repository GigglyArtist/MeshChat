# Ручные тесты на устройствах

Журнал ручной проверки MeshChat (ARCHITECTURE.md §16.2). Автотесты проверяют логику на тестовой сети и через `127.0.0.1`. Ручные тесты проверяют то, чего автотесты не видят: настоящий радиоканал, Bonjour, разрешения iOS, сворачивание приложения.

## Как собрать на устройство

1. Подключить iPhone кабелем к Mac, открыть `MeshChat.xcodeproj`.
2. В Xcode выбрать iPhone в списке устройств → **Run** (⌘R).
3. Для бесплатного Apple ID: Signing & Capabilities → Team → свой Apple ID. На iPhone: Настройки → Основные → VPN и управление устройством → доверять разработчику.
4. При первом запуске разрешить «Локальная сеть» и «Камера».
