# MeshChat — Журнал ручных тестов на устройствах

Файл ведётся в соответствии с §16.2 ARCHITECTURE.md.  
Каждая сессия тестирования — отдельная запись в таблице.  
Тесты проводятся только на **реальных устройствах** (peer-to-peer Bonjour не работает в симуляторе).

---

## Как собрать и установить

```bash
# 1. Открыть MeshChat.xcodeproj в Xcode
# 2. Подключить два iPhone (USB или Wi-Fi)
# 3. Выбрать схему MeshChat, таргет — реальное устройство
# 4. Product → Run (⌘R) на каждом устройстве
# 5. При первом запуске разрешить «Локальную сеть»
```

Минимальные требования: iOS 17.0+, два iPhone, общий Wi-Fi (или прямой peer-to-peer).

## Сценарии (§16.2)

| № | Сценарий | Шаги | Ожидание | Результат | Заметки |
|---|---|---|---|---|---|
| 1 | Базовый чат | 1. Хост создаёт комнату. 2. Клиент сканирует QR. 3. Оба отправляют по 3 сообщения. | Все сообщения доставлены в обе стороны. | | |
| 2 | Лимит участников | 1. Хост + 4 клиента. 2. 5-й клиент пытается войти. | 5-й не входит; переписка остальных не нарушена. | | |
| 3 | Чужой QR | Клиент сканирует QR от другой комнаты. | Отказ с понятным сообщением; никаких данных чужой комнаты не сохраняется. | | |
| 4 | Клиент на 10 с теряет сигнал | 1. Клиент перелетает в мёртвую зону (или включает авиарежим на 10 с). 2. Возвращается. | Чат продолжается; «X отключился» **не** появляется; баннер «Reconnecting» исчезает. | | |
| 5 | Клиент пропадает на 30 с | Клиент отключается на > 20 с (grace period). | Остальные видят «X отключился». | | |
| 6 | Хост завершает комнату | Хост нажимает «Завершить». | У всех клиентов немедленно «Хост завершил сессию»; UI закрывается. | | |
| 7 | Хост сворачивает приложение на 10 с | 1. Хост сворачивает на 10 с. 2. Возвращается. | Клиенты переподключаются (баннер «Reconnecting» → исчезает); переписка продолжается. | | |
| 8 | История чатов | Два чата с одним и тем же другом (разные сессии). | В истории у обоих две сессии с отдельными сообщениями. | | |
| 9 | Запрет «Локальной сети» | В настройках iPhone → MeshChat → запретить «Локальную сеть». Запустить/переоткрыть приложение. | Понятное сообщение в UI; приложение не падает. | | |

## Дополнительные сценарии этапа 08b (ADR-11)

| № | Сценарий | Шаги | Ожидание | Результат | Заметки |
|---|---|---|---|---|---|
| 10 | Клиент сворачивает на 10 с и возвращается | 1. Переписка идёт. 2. Клиент сворачивает (Home). 3. Через 10 с открывает. | Баннер «Reconnecting» → «Active»; переписка продолжается; сообщения, отправленные хостом в паузу, доставлены после возврата. | | |
| 11 | Клиент сворачивает на > 20 с | 1. Клиент уходит в фон на > 20 с. | Хост и другие клиенты видят «X отключился»; у самого клиента UI показывает «Сессия завершена». | | |
| 12 | Хост сворачивает на 10 с (listener упал и перезапустился) | 1. Хост сворачивает. 2. iOS может забрать Bonjour-сокет. 3. Через 10 с хост возвращается. | Listener перезапускается (автоматически); клиенты видят разрыв ≤ 20 с и reconnect; переписка продолжается. | | |
| 13 | Listener перезапустился: клиент подключается заново | После сценария 12, пока хост был в фоне или сразу после возврата: клиент отправляет сообщение. | Сообщение доставляется хосту; доставляется другим клиентам. | | |
| 14 | Запрет «Локальной сети» у хоста в активной комнате | В настройках запретить «Локальную сеть» при открытой комнате. | Хост получает `.localNetworkDenied`; комната завершается с понятным сообщением; клиенты видят «Хост отключился». | | |
