# MeshChat

MeshChat — офлайн-мессенджер для небольших групп до 5 человек. Работает поверх Network.framework (Bonjour + peer-to-peer Wi-Fi), не требует интернета и серверов: одно устройство создаёт комнату, остальные входят по QR-коду.

## Требования

- Xcode 16+
- iOS 17.0+
- Wi-Fi (интернет не нужен)
